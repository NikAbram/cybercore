# Дизайн-система CYBERCORE

Статус: результат этапа 2 для закрытой предварительной версии. Визуальная система готова к применению во всех секциях, а изображения имеют статус `draft` и должны быть подтверждены или заменены до публичного запуска.

## Концепция

«Контрольная комната после полуночи»: спокойная тёмная архитектура, точная крупная типографика и одна красная линия маршрута. Hero — единственный сильный визуальный жест. Карточки и следующие секции не получают постоянного свечения, одинаковых скруглений или декоративных технических подписей.

## Токены

| Группа            | Токены                                                                                                        |
| ----------------- | ------------------------------------------------------------------------------------------------------------- |
| Цвет              | `ink #09090D`, `surface #17171F`, `surface-strong #20202A`, `signal #EF233C`, `text #F5F5F7`, `muted #9292A3` |
| Шрифты            | Inter — весь русский текст и интерфейс; Space Grotesk — `CYBERCORE`, латинские названия зон и числа           |
| Контейнер         | Максимум 1920 px, боковые поля `clamp(16px, 4vw, 80px)`                                                       |
| Сетка             | 12 колонок на desktop, 8 на tablet, 4 на mobile; межколонник `clamp(16px, 2vw, 32px)`                         |
| Вертикальный ритм | Базовый шаг 8 px; пространство секции `clamp(88px, 11vw, 160px)`                                              |
| Радиусы           | Основные изображения и поверхности без скругления; круг используется только как индикатор состояния           |

Шкала текста определена fluid-токенами `--text-sm`, `--text-md`, `--text-lg`, `--text-xl`, `--text-section`, `--text-hero`. На ширине 320 px основной текст остаётся не меньше 16 px.

## Состояния элементов

- Основной CTA: красная заливка; hover — только небольшое повышение яркости, без свечения и смещения.
- Ссылки и контролы: видимый двухпиксельный `focus-visible` с отступом 4 px.
- Изображения: допустим сдвиг масштаба до 2.5% внутри обрезанной области; карточка не меняет положение.
- Disabled: сниженная непрозрачность, курсор `not-allowed`, текстовое объяснение рядом для критичных действий.
- Ошибка: `signal` плюс иконка и конкретный текст; состояние никогда не кодируется только цветом.
- Движение: маска hero и появление текста один раз; при `prefers-reduced-motion` анимации и плавная прокрутка отключены.

## Кадрирование

| Ассет   | Desktop                                 | Mobile              | Фокус                                                        |
| ------- | --------------------------------------- | ------------------- | ------------------------------------------------------------ |
| Hero    | правая визуальная колонка, высокий кадр | 4:5–1:1 под текстом | ряды станций и красная линия, `64% 50%`                      |
| Зоны    | редакционный ритм 5:6 и 4:5             | единый 4:3          | ключевое рабочее место, фокус хранится в `src/data/media.ts` |
| Галерея | смешанная сетка 2:1                     | один столбец        | периферия, зал, отдых, команда, hardware, посадка            |

`next/image` получает `fill`, предсказуемый контейнер с `aspect-ratio` и `sizes`. Hero загружается с `priority`; остальные изображения остаются ленивыми по умолчанию.

## Источник и права на изображения

Все десять файлов в `public/images/cybercore/` сгенерированы специально для CYBERCORE встроенным инструментом OpenAI ImageGen 15.10.2026 и затем конвертированы в WebP без содержательных правок. Сторонние фотографии, логотипы и изображения конкурентов не использовались.

Общий prompt-набор: премиальный тёмный компьютерный клуб, фотореалистичная коммерческая интерьерная съёмка, матовые чёрные материалы, один направленный красный акцент, безопасные поля кадрирования; без текста, логотипов, водяных знаков, узнаваемых лиц, радужной RGB-подсветки и чрезмерного неона. Отдельные сцены: hero, STANDARD, VIP, BOOTCAMP, периферия, общий зал, зона отдыха, командная комната, системный блок и игровое кресло.

Статус прав: внутренние сгенерированные материалы для закрытой предварительной версии. Перед публичным коммерческим запуском владелец должен подтвердить возможность финального использования по применимым условиям аккаунта OpenAI либо заменить их утверждённой фотосъёмкой. BOOTCAMP-изображение не используется как доказательство точного количества мест: вместимость подтверждается отдельно.

## Самокритика

Первый вариант направления мог превратиться в типовой «чёрный фон + красный неон». Поэтому красный оставлен только в CTA, маршрутной линии и локальном свете фотографий; крупные поверхности не окрашены, карточки не светятся и не подпрыгивают. Нумерация используется только у трёх зон как порядок выбора, а не как декоративная подпись каждой секции.
